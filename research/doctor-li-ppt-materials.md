## 分文件提炼

### 1. `鼻咽癌早筛早诊.pptx`

核心信息：

- 鼻咽癌在中国南方、东南亚更高发，需提高警惕
- 早期症状识别很关键，尤其是：
  - 鼻塞
  - 回吸鼻涕带血或鼻出血
  - 无痛性颈部淋巴结肿大
  - 单侧耳闷耳鸣或听力下降
  - 视力改变、复视、颅神经受压症状
- 早筛工具不是单一的，呈阶梯化：
  - 电子鼻咽镜
  - 窄带成像（NBI）内镜
  - EB 病毒血清学
  - CT
  - 增强 MRI
  - PET-CT
  - 鼻咽部黏膜细胞稳定性 FH 检测
- 其中 PPT 里明显更强调：
  - `增强 MRI` 适合鼻咽癌早期筛查和治疗后复发评估
  - `PET-CT` 不是常规首选筛查工具
  - 对可疑病例要动态复查，而不是一次阴性就放掉

建议沉淀的 `kind`：

- `diagnostic_principle`
- `risk_rule`
- `doctor_thought`
- `patient_education`

### 2. `复发性鼻咽癌的治疗策略.pptx`

核心信息：

- 复发性鼻咽癌治疗要比较：
  - 再程放疗
  - 化疗
  - 靶向治疗
  - 手术治疗
- PPT 明确呈现一个重要价值判断：
  - 可切除复发鼻咽癌时，手术是需要认真优先考虑的挽救方案
- 对再程放疗，PPT 强调并发症问题：
  - 颅神经麻痹
  - 颞叶坏死
  - 放射性颅底骨坏死
  - 颈内动脉破裂大出血
- 对内镜手术，PPT 强调：
  - 近 20 年颅底外科和设备进步推动开放术式向内镜微创术式发展
  - 鼻内镜下手术治疗颅底鼻咽肿瘤已成为主流方向
  - 对局部残留或复发病例，手术可在生存率和生活质量之间取得更好平衡

建议沉淀的 `kind`：

- `treatment_principle`
- `clinical_strength`
- `doctor_thought`
- `risk_rule`

### 3. `张悦鼻咽癌治疗新思考.pptx`

这份更像李勇医生吸收外部学术观点后可转化的参考材料，适合作为低一档权重资料。

可提炼的稳定观点：

- 鼻咽癌早期诊断率低，很多患者确诊已是局部晚期
- 再程放疗的长期效果和并发症问题都不理想
- 对残留或复发病灶，综合治疗和手术价值被重新重视
- 内镜微创入路在复发 / 残留鼻咽癌里的角色明显增强

建议入库方式：

- 作为 `doctor_thought` 或 `research_direction`
- `importance` 不要高于李勇本人 PPT 中的直接表达

### 4. `儿童鼻窦炎抗生素使用共识.pptx`

这是非常适合做问答资料库的一份，因为临床判断边界很清楚。

可直接沉淀的稳定原则：

- 儿童慢性鼻窦炎不能简单照搬成人治疗经验
- 目前缺乏证据支持常规短期或长期口服抗生素用于儿童 CRS
- 盐水冲洗和鼻内皮质类固醇仍是儿童慢性鼻窦炎主要治疗方式
- 腺样体因素在儿童 CRS 中很重要
- 合并眶内或颅内并发症时，抗生素仍有明确位置
- 对严重急性发作、疑似并发症病例，需要影像学支持后及时处理
- 局部抗生素冲洗是可讨论方向，但仍缺高质量证据

适合形成的资料类型：

- `diagnostic_principle`
- `treatment_principle`
- `risk_rule`
- `doctor_thought`

### 5. `过敏性鼻炎四位一体(1).pptx` / `过敏性鼻炎四位一体2.pptx` / `过敏性鼻炎诊治新概念-2.pptx`

这三份 PPT 内容高度重叠，可以作为一个大主题合并整理。

最有价值的稳定观点包括：

- 过敏性鼻炎不能只靠“回避过敏原”或“单点药物”，而要做“四位一体”综合管理
- 四位一体包含：
  - 避免接触过敏原
  - 规范化药物治疗
  - 特异性免疫治疗
  - 医生患者教育
- 李勇 PPT 里非常强调“症状分型”，尤其是儿童过敏性鼻炎：
  - 卡他型
  - 鼻阻型
  - 多动型
  - 鼻后滴漏型
  - 干燥型
- 对不同分型，局部治疗和全身治疗建议不同，这部分非常适合做问答模板
- 对尘螨，PPT 观点很明确：
  - 尘螨是中国最主要吸入性过敏原之一
  - 对持续性过敏性鼻炎，单纯“避免”往往不够，需要考虑免疫治疗和长期管理
- 对食物过敏，PPT 强调：
  - 不能只凭特异性 IgE 阳性就简单忌口
  - 过度忌口有害无益
  - 回顾性排查和食物日记很重要
- 对益生菌 / 肠道菌群，PPT 更像是“扩展性医生观点”：
  - 其定位更偏辅助性、系统性管理
  - 不适合被写成强推荐金标准
- 对 AIT（脱敏 / 特异性免疫治疗），PPT 强调长期意义：
  - 起效有时间窗
  - 完成疗程后对长期症状控制和慢病管理有价值

建议沉淀的 `kind`：

- `doctor_thought`
- `treatment_principle`
- `patient_education`
- `follow_up_rule`
- `research_direction`

## 跨 PPT 可提炼的李勇风格线索

虽然 PPT 不是门诊对话，但已经能看出一些稳定倾向：

- 喜欢把问题系统化，而不是只给单点结论
- 重视“分型”和“分层处理”
- 对指南证据边界很敏感，不轻易把争议方案说成常规推荐
- 对慢病倾向长期管理视角，而不是一次性解决
- 对复发肿瘤更关注真实获益与并发症代价的平衡

这些内容很适合转成：

- `thinking_style`
- `doctor_thought`
- `follow_up_rule`
